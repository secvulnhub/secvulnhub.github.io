winadsec

Windows Active Directory pentest and post-exploitation. Full attack chain from unauthenticated discovery through UAC bypass, reboot-persistent implant installation, Sliver C2 session management, and end-to-end payload delivery generation.

Overview

winadsec is a full-chain Windows Active Directory pentest and post-exploitation module built for the secV framework. It integrates unauthenticated discovery, credential-based enumeration, lateral movement, UAC bypass, reboot-persistent implants, Sliver C2 session management, and a complete payload delivery pipeline — all driven by a single JSON context from the secV shell.

The module spans three major capability areas: AD assessment (enumerate, enumerate, loot), post-exploitation (escalate, persist, C2), and payload generation (implant → shellcode → DLL → ISO). All output is written to output_dir.

AUTHORIZATION REQUIRED. Only run against systems you own or have explicit written permission to test. Unauthorized use may violate the CFAA and equivalent computer fraud laws. Always obtain written authorization before any engagement.

Full Attack Chain

End-to-end compromise from unauthenticated discovery to domain-wide credential dump. Each step feeds the next.

01
gen_sliver — Generate Implant
operation: gen_sliver builds a Windows EXE via sliver-client generate that callbacks to your Sliver server on c2_http_port (default 8443). Garble obfuscation + evasion flags enabled.
02
gen_shellcode — EXE → Shellcode
Runs donut -f 1 -a 2 on the EXE to produce position-independent x64 shellcode.
03
gen_payload — Encrypt Shellcode
XOR-encrypts shellcode with 16-byte key, prepends 4-byte LE length → update.bin. Serve via HTTP: python3 -m http.server 9000.
04
gen_proxy_dll — Compile version.dll
Zig cross-compiles a transparent version.dll proxy that patches AmsiScanBuffer and EtwEventWrite, downloads + decrypts update.bin via WinHTTP, and injects shellcode into explorer.exe via CreateRemoteThread. Forwards all 16 real exports.
05
gen_iso — Delivery Package
Bundles malicious version.dll + Microsoft-signed OneDriveSetup.exe into an ISO. User mounts → double-clicks signed EXE → DLL loads → shellcode runs → C2 session. SmartScreen allows the signed EXE; DLL is never directly executed.
06
Deliver + Wait for Session
Host ISO on HTTP and send the link. After mount and double-click: sliver_sessions to confirm callback, sliver_whoami to verify integrity level.
07
uac_bypass / lsa_fix — Escalate
Fodhelper HKCU registry hijack elevates payload to high integrity. lsa_fix sets LimitBlankPasswordUse=0 to enable blank-password SMB authentication.
08
persistence — Survive Reboot
wmi_sub installs a WMI EventFilter + CommandLineEventConsumer that fires 60s after boot. Not shown in Autoruns by default. Fallback: run_key (low-priv) or service (admin).
09
auto — Full AD Assessment
discover → vulncheck → users → groups → shares → passpol → asreproast → kerberoast → bloodhound → privesc_check → lsa_fix → loot
10
sliver_getsystem + secrets — Domain Compromise
Escalate to SYSTEM, dump SAM/LSA/NTDS hashes via secretsdump. Crack offline with hashcat -m 1000 (NTLM) or -m 13100 (Kerberoast).

Assessment Operations

Set via set operation <name>. Credential tags indicate requirement level.

discover no creds
Unauthenticated DC fingerprint: TCP ports, SMB null session, LDAP rootDSE, OS, signing, naming contexts, functional level.
users optional
LDAP enum (auth) or SAMR RID brute (null). Returns SIDs, UAC flags, SPNs, preauth status.
groups creds
LDAP group enum with full member lists. Identifies DA/EA/nested membership.
shares optional
SMB share inventory with READ/WRITE tests and root directory listing.
passpol optional
Domain password policy: lockout threshold, observation window, min length, complexity, history.
kerberoast creds
Find SPN accounts via LDAP, request TGS. Outputs $krb5tgs$23$ hashcat hashes.
asreproast no creds
Probe userlist for DONT_REQUIRE_PREAUTH. Dumps AS-REP hashes — no credentials needed.
spray no creds
Lockout-aware SMB spray. Reads passpol, leaves 2-attempt buffer, skips krbtgt/Admin/Guest.
vulncheck no creds
Zerologon, PetitPotam, NoPac, MachineAccountQuota, AD CS (ESC8), SMBv1, SMB signing.
bloodhound creds
bloodhound-python collection, BH-compatible JSON zip output for attack path analysis.
loot creds
Scrape shares for GPP cpassword, unattend.xml, web.config, SSH keys, .kdbx, .env files.
secrets admin
Dump SAM/LSA/NTDS via impacket-secretsdump. Requires domain admin or local admin.
exec creds
Remote command via impacket-wmiexec (or native WMI fallback). Output via C$ temp file.
privesc_check creds
PowerShell privesc audit with AMSI bypass: unquoted services, writable binaries, AIE, UAC config, token privs, stored creds, PATH hijack, elevated autoruns, LimitBlankPasswordUse.
auto optional
Full safe pipeline: discover → vulncheck → users → groups → shares → passpol → asreproast → [kerberoast / bloodhound / privesc_check / lsa_fix if creds provided].

Post-Exploitation

uac_bypass

Writes a payload command to HKCU\Software\Classes\ms-settings\shell\open\command via PowerShell -EncodedCommand (through WMI exec), then triggers an auto-elevating Windows binary. The elevated process runs the payload at high integrity. Registry is cleaned up automatically.

uac_methodKeyTriggerNotes
fodhelperms-settings\...commandfodhelper.exeDefault. Needs DelegateExecute="". Win10/11.
eventvwrmscfile\...commandeventvwr.exeFallback. No DelegateExecute needed.
wsresetAppX82...\Shell\open\commandwsreset.exeUWP path. Newer Win11 builds.
uac_payloadEffect
lsa_fixSet HKLM LimitBlankPasswordUse=0 (fixes blank-password SMB auth)
add_adminAdd current user to local Administrators group
disable_defenderSet-MpPreference -DisableRealtimeMonitoring $true
enable_rdpSet fDenyTSConnections=0 in HKLM (enable RDP)

lsa_fix

Shortcut for uac_bypass with uac_payload=lsa_fix. Disables LimitBlankPasswordUse via UAC-elevated reg.exe. Verifies the write succeeded and returns bypassed: true/false.

Persistence

All methods survive reboot and shutdown. Install with operation: persistence, remove with remove: true. Use persist_name to blend in (e.g. WindowsSecurityHealth, MicrosoftUpdateHelper).

persist_methodPrivilegeTriggerStealthNotes
run_key low-priv User logon ★★☆ HKCU\...\Run. Visible in Autoruns. Default fallback.
startup_folder low-priv User logon ★☆☆ Copies EXE to user Startup folder. Very visible.
scheduled_task low-priv On logon ★★☆ schtasks /sc onlogon. Task Scheduler visible.
service admin Boot (before logon) ★★☆ Auto-start service. Fires before any user logs in.
wmi_sub admin ~60s after boot ★★★ WMI EventFilter + CommandLineEventConsumer. Not in Autoruns. Hardest to detect.
all_user admin Any user logon ★★☆ HKLM\...\Run. Fires for every user that logs in.

Sliver C2 Bridge

All Sliver ops use the installed sliver-client binary with the operator config auto-loaded from ~/.sliver-client/configs/. Single-command ops use implant -s SESSION_ID; multi-step ops use RC script files with console --rc.

sliver_sessions
List all active sessions: ID, name, transport, remote addr, hostname, username.
sliver_exec
Execute shell command via cmd.exe /Q /c. Returns stdout + stderr.
sliver_upload
Upload local file to remote path. Deliver payloads, scripts, and tools.
sliver_download
Download remote file to local path. Exfiltrate loot, creds, configs.
sliver_ps
List remote processes with PID, PPID, name, owner. Identify injection targets.
sliver_spawndll
Reflective DLL injection into target PID. Used for UAC bypass DLL delivery.
sliver_getsystem
Escalate to NT AUTHORITY\SYSTEM via Sliver built-in. Requires high-integrity session.
sliver_registry
Read/write Windows registry. Omit reg_value to read; provide it to write.
sliver_whoami
Return current user + integrity level via whoami.
sliver_screenshot
Capture desktop screenshot, save to output_dir.
sliver_impersonate
Steal token of a logged-in user. Requires SeDebugPrivilege (high-integrity).
sliver_make_token
Create logon session with given creds without spawning new process (PtH-compatible).

XOR Key

Default key (hex): 4e3a7f1289abcdef0123456789fedcba. Override with the xor_key parameter. The proxy DLL and update.bin must use the same key.

Proxy DLL internals

On DLL_PROCESS_ATTACH: loads real System32\version.dll, resolves all 16 exports, spawns payload_thread. Thread patches AmsiScanBuffer and EtwEventWrite in-process, opens a WinHTTP connection to C2_HOST:C2_PORT/C2_PATH, reads the XOR-encrypted update.bin, decrypts it, and calls VirtualAllocEx + WriteProcessMemory + CreateRemoteThread on explorer.exe. Shellcode survives host-process exit since it runs inside explorer.
