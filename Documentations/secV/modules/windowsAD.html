About

Mission

secV brings together fragmented offensive tooling into one coherent, scriptable framework — so you spend less time gluing tools together and more time finding real vulnerabilities.

01
Modular by design
Each module reads JSON from stdin and writes structured results. Compose operations via shell pipelines or drive them programmatically from the secV interactive shell.
02
Full-chain coverage
From unauthenticated discovery through credential dumping, payload generation, and C2 session management — secV covers the full engagement lifecycle in one framework.
03
Authorization first
Every module includes authorization warnings. secV is built for legal engagements — pen tests, CTFs, and lab environments where you have explicit written permission to test.
04
Open source, MIT
All modules are MIT licensed. Fork, extend, contribute. The framework grows through community submissions — new modules, new CTF rooms, new techniques.

Get Involved

Contribute

New modules, CTF rooms, bug reports, and documentation improvements are all welcome. Open a pull request on GitHub.

→
Submit a module
Build a new secV module following the JSON stdin/stdout convention. Open a PR with the module source and a documentation HTML page matching this site's style.
→
Add CTF rooms
Add TryHackMe or HackTheBox autopwn scripts to the CTFs repo. Scripts receive the target IP as the first positional argument and print flags in THM{} / HTB{} format.
→
Report issues
Found a bug or broken operation? Open an issue on GitHub with the module name, operation, exact command, and observed vs. expected output.
