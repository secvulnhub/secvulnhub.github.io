SecVulnHub is a place for cyber engineers, coders, and security people to pool their work. Not a company, not a product — just a collective that got tired of good tools being scattered everywhere and decided to put them somewhere central and open.

Whether you're a pentester, a student, a dev who does CTFs on weekends, or just someone who built something useful — you're welcome here. Contribute a tool, improve an existing one, or just use what's already here. No gatekeeping.

05 Community

OUR
CONTRIBUTORS.

Everyone who has shipped code to SecVulnHub. Loaded live from GitHub — if you've merged a PR, you're here.

01
Fork & clone the repo
Fork secvulnhub/secV on GitHub, clone locally, and create a feature branch for your module.
git clone https://github.com/YOUR_USERNAME/secV
cd secV && git checkout -b feat/my-module
02
Scaffold with gen_module.py
Interactive scaffold creates module.json, the entry Python script, and a requirements stub automatically.
python3 gen_module.py
# → tools/<category>/<name>/module.json
# → tools/<category>/<name>/<name>.py
03
Implement the stdin/stdout protocol
Your module reads one JSON line from stdin (target + params), does the work, and writes FINDING: lines to stdout.
import json, sys
data   = json.loads(sys.stdin.readline())
target = data["target"]
params = data.get("params", {})

# ... do your work ...

print(f"FINDING: {json.dumps({'title': 'found', 'severity': 'HIGH'})}")
04
Add deps to the global rqm.md
Add pip packages under #python and system packages under each distro section (#pacman / #apt / #dnf / #zypper / #apk) in the root rqm.md. The install.sh reads this automatically.
05
Test and open a PR
Run bash install.sh, test your module with use <module> inside the secV shell, write a short doc page matching the other module docs, and open a PR against main with a demo in the description.
