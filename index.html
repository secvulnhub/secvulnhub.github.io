Current Working Project

secV
Modular offensive security framework with a REPL shell, tab-completion, and Linux-native navigation. Wraps nmap, masscan, msfvenom, Frida, ADB, apktool and more into a single coherent workflow. Currently ships with netrecon and android_pentest.
